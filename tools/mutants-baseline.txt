# Mutation survivor baseline, read by tools/mutants-ratchet.py.

# One line per crate that defines a `cargo_mutants_test` target:
#
#     <crate> <survivors>
#
# A sweep fails a crate whose survivor count is above the number
# here. It passes a crate whose count is below, and asks for the number to be
# lowered. Lower it in the same change that killed the mutants.
#
# `unseeded` means no number is checked in yet. The ratchet is dormant for
# that crate: the sweep reports its survivor count and gates nothing on it.
# The structural checks in tools/mutants-ratchet.py still apply, so a crate
# with no number is still unable to report a killed shard as a clean sweep.
#
# `unseeded` crates have not completed a trustworthy full sweep since the
# ratchet was written. A sweep is a manual job of several hours, and a number
# written from a partial run would be a guess. Take a count only from a complete
# run, which prints the line to check in:
#
#     tools/mutants-ratchet.py <crate> --record
#
# Recorded run metadata and artifact checksums live in
# qualification/milestone-19-mutation-baselines.json. Each number here must
# match its record, and `tools/mutants-record.py --check` fails when they
# differ. Record a new sweep with `tools/mutants-record.py --capture`; see
# README.md, "Seeding a crate by hand".
