# Baseline for the operating-envelope soak, read by tools/soak-gate.py.
#
# One line per metric that the soak is expected to report:
#
#     <signal>/<phase>/<metric> <value>
#
# Latencies are microseconds, rates are accepted rows per second, resident
# memory is KiB, and recovery is seconds. The gate fails a metric that moves
# against the number here by more than 1.5 times: a latency, memory, request
# count or recovery time above it, or a rate below it.
#
# This file is also the inventory. A report with no value for a line here
# fails, and so does a value with no line here. Those checks apply whether or
# not a number is set, so a phase that stops measuring cannot pass as clean.
#
# Every line is `unseeded`. No stable-runner soak has run yet, so the ratchet
# is dormant and only the inventory applies. Numbers from a shared GitHub
# runner do not belong here, because a different host gives different numbers.
# To seed the file, run the soak on the stable runner recorded in
# docs/operating_envelope.md and record its report:
#
#     bazel test --config=scale //crates/integration:soak_envelope_docker_test
#     tools/soak-gate.py --record \
#         bazel-testlogs/crates/integration/soak_envelope_docker_test/test.outputs/soak-report.json
#
# Check the recorded lines in with the host shape, commit, and report digest
# beside them.
