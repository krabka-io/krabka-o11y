# krabka-o11y v0.4.2

This release includes the certificate verification and trust-root updates from
the unpublished v0.4.1 candidate: Rustls 0.23.46, rustls-webpki 0.103.16 and
webpki-root-certs 1.0.10.

The release report now requires all 178 source-defined Loki template cases.
Its previous count of 171 rejected a complete passing test result. The exact
case identities, requests, independent expected results and artifact checks
remain required. A regression check binds the count to the source fixture.

Query compatibility is partial. Of the 1,433 pinned upstream query features,
93 have complete reviewed mappings, 272 have partial mappings and 1,068 are
uncovered. See the [query coverage contract](../query_language_conformance_proposal.md)
and its feature inventory for the limits. This release does not claim complete
upstream query conformance. Release tests require every selected runtime suite
and all source, request, result, count, checksum and provenance checks; the
standalone query workflow retains its full-conformance `strict` mode.

The report now routes Loki template and Tempo output/scope executions to their
reviewed registry identities. This restores 107 witness bindings and applies
their required semantic checks without changing the feature inventory. Two
reviewed Tempo label totals use the source fixture's floating-point `1.0`
identity; typed comparisons remain exact.

The service Rust code and query fixtures are unchanged from the v0.4.1
candidate. This patch updates the workspace version and release validation
metadata, and includes this versioned release note. The stopped v0.4.1 tag
remains unchanged.

The release gates check the exact source, compatibility report, proofs,
container suites, scale tests, four-signal installation and browser WASI lab.
The coordinated broker ecosystem qualification remains pending until its
frozen candidate passes the declared gates and independent pilot acceptance.
