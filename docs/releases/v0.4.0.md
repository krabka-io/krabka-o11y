# krabka-o11y v0.4.0

This is the first supported krabka-o11y release.

Supported compatibility baselines are Loki 3.7.7, Mimir 3.2.1, Tempo 3.0.3,
Pyroscope 2.3.1, Grafana 13.2.2, Prometheus 3.14.0, and Alloy 1.19.2. The
release assets include the immutable compatibility report, an SPDX SBOM,
GitHub provenance and SBOM attestations, and checksums.

Persisted data: durable Kafka records and Parquet blocks carry format version 1. Krabka is greenfield, so this release reads no older format. A reader refuses a block, or a record that Krabka writes, without a version marker. Install this release on empty broker and object-store data.

Install the release digest on every role. Wait for `/ready` and query all four signals. Do not deploy a tag without its attached qualified compatibility report.
